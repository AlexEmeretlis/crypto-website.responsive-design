About Me

Five years ago, I was watching candlestick charts, not code editors. Scalping, day trading, swing trading — running everything through a professional terminal connected directly to the exchange via API keys. I learned to read markets the hard way: through wins, through losses, and through the kind of discipline that only comes from having real money on the line. Somewhere along the way, I got curious about the tools I was using every day. What was actually happening behind that terminal? How did the API calls work? Could I build something like this myself? That curiosity turned into a full career shift. I'm now teaching myself full-stack development, with a clear focus: fintech. Not because I'm leaving trading behind, but because I finally understand both sides of the screen — the trader who needs the tool, and the developer who builds it. This blog is where I document that journey — the market knowledge I bring with me, and the code I'm learning to write.
